# greenscreen-demo
Demo of how a green screen works using NumPy, Matplotlib, and OpenCV

1. Install Libraries:

pip install opencv-python numpy matplotlib

2. Put a greenscreen video or photo in the same folder as the script and change line 9 in greenscreen.py to your greenscreen file name

3. Put a background photo in the same folder as the script and change line 8 in greenscreen.py to your background file name

4. Run greenscreen.py
